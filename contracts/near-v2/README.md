The contract interface and payment model match the repository's Standard v2 ABI and adapter: admin/treasury/USDC configuration, six invoice statuses, NEP-141 `ft_on_transfer`, separate treasury settlement, admin refund, stuck-operation recovery, and the same view methods. The ABI also records `contract_source_metadata`, which may be generated by the NEAR build metadata tooling.

**Verification limitation:** this source snapshot is being added for transparency and judge review. The source has not yet been independently rebuilt with the exact historical toolchain and compared byte-for-byte against the ABI-recorded Wasm hash. Do not describe this repository copy as a cryptographically verified reproduction until that comparison is completed.

## Critical safety boundary

This is a source/documentation addition only. It does not deploy, upgrade, initialize, migrate, or otherwise modify `v2.studentfee.testnet`. Never redeploy this contract to the existing account as part of routine app changes.

## Payment due-date rule

The current source rejects an incoming payment when `block_timestamp / 1_000_000 > invoice.due_date` and `is_invoice_payable` also returns false after the due date. This confirms the overdue-payment restriction in the source snapshot. Any change to this rule is a smart-contract behaviour change and requires explicit owner approval, tests, a reviewed migration/deployment plan, and must not be made silently.
